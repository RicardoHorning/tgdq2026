# Sistema de Avaliação TGDQ - SENAI

Este projeto contém a plataforma web completa para a Unidade Curricular de Tratamento e Gerenciamento de Dados Quantitativos (TGDQ).

## Arquivos Incluídos:
1. `login.html`: Tela de Login e Primeiro Acesso do Aluno.
2. `index.html`: Portal Principal com Perfil, Gerador de CSV Único, Roteiro Guiado de 8 horas e Validação de Gabarito.
3. `dashboard.html`: Painel do Professor em tempo real.

## Como Publicar no GitHub Pages:
1. Extraia este arquivo `.zip`.
2. Envie os arquivos `login.html`, `index.html` e `dashboard.html` para a raiz do seu repositório no GitHub.
3. Vá em **Settings > Pages** no repositório e ative a publicação a partir da branch `main`.
4. O link público do aluno será: `https://seu-usuario.github.io/seu-repositorio/login.html`
5. O link do painel do professor será: `https://seu-usuario.github.io/seu-repositorio/dashboard.html`
